## Getting Started

### Prerequisites

- Node.js 18 or newer
- npm

### Installation

```bash
git clone https://github.com/rumachoudhury/ruma-app.git
cd ruma-app
npm install
```

### Development

```bash
npm run dev
```

Open the local URL shown in the terminal, usually `http://localhost:5173`.

### Production Build

```bash
npm run build
npm run preview
```

### Quality Checks

```bash
npm run lint
```
